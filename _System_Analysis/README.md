# Explore Egypt - System Analysis & Design Package

## Files
- `Explore_Egypt_System_Analysis.drawio` - editable multi-page diagrams.net source (12 pages).
- `03_System_Analysis_and_Design.pdf` - formatted report for submission.
- `03_System_Analysis_and_Design.md` - editable Markdown report/source.
- `diagrams/` - SVG diagram sources.
- `previews/` - PNG diagram previews.

## Open and edit in diagrams.net
1. Open https://app.diagrams.net/
2. Choose **Device** (or your preferred storage location).
3. Use **File > Open From > Device** and select `Explore_Egypt_System_Analysis.drawio`.
4. The file contains 12 pages. Edit labels, shapes and connectors as needed.
5. To export a page: **File > Export as > PDF / PNG / SVG**.

## Upload to GitHub
Upload the PDF and `.drawio` file, and optionally the Markdown report and the `diagrams/` source folder, into the `Explore-Egypt/Docs` repository.

## Review notes
- Backend/database choices and some business policies are marked proposed/open where they have not been confirmed by the team.
- Pending booking seat reservation and cancellation policy require team/instructor confirmation.
- Deployment diagram is conceptual; it does not claim that hosting has been completed.
- ERD V2 is the chosen baseline because it separates Tours, Departures and Bookings and models ordered TourStops.
